# LaslesVPN Clone

Ini adalah clone sederhana dari landing page *LaslesVPN, dibuat menggunakan **Next.js* dan *Tailwind CSS*. Proyek ini bertujuan untuk latihan membuat UI responsif dan terstruktur dengan baik menggunakan teknologi modern.

## ✨ Fitur

- Tampilan responsif untuk desktop dan mobile
- Komponen reusable
- Styling menggunakan Tailwind CSS
- Struktur Next.js dengan App Router

## 🛠 Teknologi yang Digunakan

- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)

## ⚙ Cara Setup

Ikuti langkah berikut untuk menjalankan proyek ini di lokal:

```bash
# 1. Clone repositori ini
git clone https://github.com/milen06/laslesvpn.git

# 2. Masuk ke folder project
cd laslesvpn

# 3. Install dependency
npm install

# 4. Jalankan server development
npm run dev
